# Sudoku Generator

A static web app, written in plain HTML, CSS and JavaScript (no framework, no build step, no server), that
generates Sudoku puzzles in **15 variants**, guarantees the difficulty you ask for and shows how every puzzle is
made, step by step, in English or Vietnamese.

**Status:** design phase. The specification is [design.md](design.md) and the task breakdown, with the phases
P0–P7 and the acceptance criteria of every task, is [task.md](task.md). This README is only a placeholder: it
grows into the full bilingual guide (running, testing, adding a variant) when the project is done.

---

# Tiếng Việt

Một ứng dụng web tĩnh viết bằng HTML, CSS và JavaScript thuần (không framework, không bước biên dịch, không máy
chủ), tạo đề Sudoku cho **15 biến thể**, đảm bảo đúng độ khó bạn chọn và cho bạn xem từng bước đề được tạo ra —
bằng tiếng Anh hoặc tiếng Việt.

**Tình trạng:** đang ở giai đoạn thiết kế. Đặc tả nằm ở [design.md](design.md); bảng phân rã nhiệm vụ, với các
giai đoạn P0–P7 và tiêu chí nghiệm thu của từng nhiệm vụ, nằm ở [task.md](task.md). README này mới chỉ là bản
tạm; nó sẽ được viết đầy đủ bằng hai ngôn ngữ (cách chạy, kiểm thử, thêm biến thể) khi dự án hoàn tất.
